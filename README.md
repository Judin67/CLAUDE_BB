# CLAUDE_BB — quant orchestration hub

Workflows (markdown SOPs), tools (Python scripts) and a strategy library for Judin's trading research.
Data source: Massive (Polygon) + SEC EDGAR.

**Start here**

- [Strategy library — PQN Strategy Vault](strategies/pqn_vault/README.md): 66 strategies, one page each, same shape, with status and backtest results as they are run.
- [Workflows](workflows/): the SOPs Claude follows for recurring tasks (Cascade, Dr. S, low-float, earnings, …).
- [Tools](tools/): the scripts that do the work. `tools/backtest_eda.py` is the standard statistical read every backtest ends in.
- [CLAUDE.md](CLAUDE.md): the map of what exists and how it is used.
