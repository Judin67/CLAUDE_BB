# Parabolic Exhaustion — Trade Grading Checklist
> Morning pre-trade grading system. Start at B. Each section upgrades your grade.
> **C = Do not trade.** B = Minimum threshold. A+ = Max conviction.

---

## ☐ GRADE B — BASELINE *(Must pass ALL 8 to take the trade)*
<!-- PPT color: Yellow header -->

| ☐ | Criterion | Minimum Threshold |
|---|-----------|-------------------|
| ☐ | **Theme** | Sector in play — any recognizable theme driving the move |
| ☐ | **ATR Extension** | 4+ ATRs in last 5 days — 1–2 convex days, not at historical high |
| ☐ | **Volume** | Above-average RVOL each day — increasing, no blow-off required |
| ☐ | **Momentum** | Mostly clean — brief pause or inside bar before final extension OK |
| ☐ | **% Gains** | High % in a short timeframe — no hesitation about speed of move |
| ☐ | **Daily Structure** | 2–3 parabolic legs — steep slope, not dramatically accelerating |
| ☐ | **Intraday Pattern** | Extended above VWAP, partial rejection — may chop before reversing |
| ☐ | **Asymmetric Target** | Retracement likely but slower — expect pops and fakeouts |

---

## ☐ GRADE A — STRONG SETUP *(All B criteria + these)*
<!-- PPT color: Orange header -->

| ☐ | Criterion | Upgrade Condition |
|---|-----------|-------------------|
| ☐ | **Theme** | Hot sector, notable player — clear retail interest building |
| ☐ | **ATR Extension** | Approaching historical ATR extension — 2 clean convex days |
| ☐ | **Volume** | 3–5x RVOL minimum — strong participation every day, climax building |
| ☐ | **Momentum** | No consolidation days — clean straight-up, only minor pauses |
| ☐ | **% Gains** | 25%+ for large caps (more for small/mid) — fast and unambiguous |
| ☐ | **Daily Structure** | 3 expanding legs — slope clearly steepening with each leg |
| ☐ | **Intraday Pattern** | Gap-up or significant extension — wick/rejection clearly forming |
| ☐ | **Asymmetric Target** | Clear downside retracement likely — trending down with some pops |

---

## ☐ GRADE A+ — MAX CONVICTION *(All A criteria + these)*
<!-- PPT color: Red/Gold header -->

| ☐ | Criterion | Maximum Condition |
|---|-----------|-------------------|
| ☐ | **Theme** | 🔥 Hottest theme, leading sector — maximum retail & media hype |
| ☐ | **ATR Extension** | Historical ATR extension exceeded — 2–3 days of sustained vertical |
| ☐ | **Volume** | 5–10x RVOL — blow-off climax candle on final exhaustion bar |
| ☐ | **Momentum** | Zero grind-up days — pure vertical momentum, no inside bars at all |
| ☐ | **% Gains** | 25–100%+ in days/weeks — low floats: aggressive extension before exhaustion |
| ☐ | **Daily Structure** | 3+ expanding legs — each steeper than the last, max convex slope |
| ☐ | **Intraday Pattern** | Wide-range exhaustion candle + long upper wick + gap-up outside BB |
| ☐ | **Asymmetric Target** | 10–80%+ unwind — large caps shallow, small caps collapse fast |

---

*Grade assigned at market open. Downgrade if structure changes intraday.*
