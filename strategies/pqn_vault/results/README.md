# Results — one folder per strategy ID

When a vault strategy is backtested, its outputs land here under its ID:

```
results/<ID>/
  returns.csv     one row per period (date · signal · return) — the table tools/backtest_eda.py reads
  trades.csv      one row per trade (entry · exit · side · size · return), if the strategy trades discretely
  eda.png         Judin's standard 2×2 figure from tools/backtest_eda.py (quarterly mean · signal-vs-return · deciles · Kelly)
  report.md       what was run (rules as built, data period, decisions on the ⚠ questions, headline stats, caveats)
```

Rules:
- Every backtest ends in `tools/backtest_eda.py`. No exceptions.
- The folder name is the strategy ID exactly as on its page (`A1`, `C10`, `P2`), not the page file name.
- Creating `results/<ID>/` is what flips the **Results** column in the index. After a run, set `build_status: backtested`
  on the strategy's page and rerun `python tools/vault_index.py index`.
- Nothing here is hand-written except `report.md`. Everything else is regenerated by the run.
